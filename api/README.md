# API

Принимает ZIP, сохраняет исходники в S3 и создаёт задания методов в PostgreSQL.
Стек и зависимости — в [pom.xml](pom.xml).

## Контракт

Эндпоинты и модели описаны в [Swagger UI](http://localhost:8080/swagger-ui.html).
[openapi.yaml](openapi.yaml) генерируется из контроллеров и DTO; вручную не редактируется.
При запущенном API из корня:

```sh
python3 infra/export_openapi.py
python3 infra/export_openapi.py --check
```

Для другого адреса добавьте `--base http://localhost:18080`.

- Каждый `.java` в ZIP — отдельная работа; подпапки сохраняются в `originalName`.
- `batchId` и `submissionId` — UUID. `pairId` — `{batchId}:{a}:{b}`, где `a < b` по UUID.
- Новый ZIP: `202`. Повтор тех же байтов: `200`, тот же пакет и исходный `title`.
  Дедупликация по SHA-256 постоянная и глобальная; перепаковка может создать новый пакет.
- Без `title` используется имя архива. Пары возвращаются без пагинации; фильтрует и сортирует фронт.
- Оценки методов независимы. Вместо недоступной оценки возвращается `null` с причиной
  `RUN_NOT_FINISHED`, `RUN_FAILED` или `NOT_PARSED`. Ноль — обычная оценка.
- Пакет получает `done`, если хотя бы один метод завершился успешно; подробности — в `runs`.
- На пару хранится один заменяемый отзыв без автора и истории.

## ZIP и тесты

Лимиты: 10 МиБ архива, 5–50 работ, 1 МиБ на запись, 50 МиБ после распаковки,
200 записей со служебными. При чтении проверяются фактические размеры и CRC.
Текст UTF-8/windows-1251 сохраняется в UTF-8; имена без UTF-8-флага читаются как CP866.

Из корня с JDK 25 и Maven 3.9+:

```sh
mvn -f api/pom.xml test
```

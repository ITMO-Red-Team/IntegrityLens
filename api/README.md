# API

HTTP-контракт описан в [OpenAPI](openapi.yaml) и
[документации](../docs/contracts.md). Сущности и правила хранения —
в [модели данных](../docs/data-model.md).

`openapi.yaml` редактируется как исходная спецификация. Backend реализует
этот контракт; экспорт из контроллеров не должен перезаписывать его.
Типы frontend генерируются из спецификации.

Стек и зависимости находятся в [pom.xml](pom.xml).

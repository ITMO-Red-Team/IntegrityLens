# API

Сервис регистрирует пользователей, выдаёт сессии, принимает Java-работы по ссылкам заданий и возвращает независимые результаты Structsim и AI. Контракт хранится в [docs/openapi.yaml](../docs/openapi.yaml) и доступен в запущенном сервисе через [Swagger UI](http://localhost:8080/swagger-ui.html).

Backend проверяет роль и владельца ресурса, хранит хеши паролей и токенов сессий. Студент сдаёт один непустой файл `.java` в UTF-8 размером до 1 000 000 байт. Сохранение сдачи, закрытие попытки и создание прогонов выполняются одной транзакцией PostgreSQL. Преподаватель может открыть повторную попытку с указанием текущего идентификатора сдачи.

Настройте `INTEGRITYLENS_PUBLIC_BASE_URL` на адрес frontend, который будет обслуживать ссылки вида `/submit/{token}`. Для браузерной сессии используйте HTTPS. Запуск backend и HTTP-проверка описаны в [infra/README.md](../infra/README.md).

Из корня с JDK 25 и Maven 3.9+:

```sh
mvn -f api/pom.xml test
```

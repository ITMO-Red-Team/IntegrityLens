# api

Java 25, Spring Boot 4.1.1, Spring JDBC, Flyway, springdoc-openapi. Сервис принимает и проверяет ZIP,
сохраняет исходники в MinIO и создаёт два прогона в PostgreSQL. API и воркеры общаются через БД и S3.

## Контракт

Источником OpenAPI являются контроллеры и DTO приложения. `api/openapi.yaml` — сгенерированный снимок
для команды фронта; вручную его редактировать не нужно. При запущенном API из корня репозитория:

```sh
python3 infra/export_openapi.py
python3 infra/export_openapi.py --check
```

Для другого адреса передайте `--base http://localhost:18080`. Спецификация использует относительный
server URL `/`, поэтому адрес запуска не меняет снимок.

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/batches` | Multipart: `archive`, `language=java`, необязательный `title` |
| GET | `/api/batches` | Пакеты, новые первыми |
| GET | `/api/batches/{batchId}` | Пакет и статусы методов |
| GET | `/api/batches/{batchId}/submissions` | Работы, оценки и топ-3 |
| GET | `/api/submissions/{submissionId}/source` | Исходник UTF-8 |
| GET | `/api/batches/{batchId}/pairs` | Все пары и отдельные оценки методов |
| GET | `/api/pairs/{pairId}` | Пара, фрагменты и отзыв |
| PUT | `/api/pairs/{pairId}/feedback` | Создать или заменить отзыв |
| GET | `/api/health` | Проверить БД и bucket |

`batchId` и `submissionId` — глобальные UUID. `pairId` равен `{batchId}:{a}:{b}`, где UUID работ
отсортированы лексикографически (`a < b`). Для работы сохраняется относительный путь из ZIP в `originalName`.
Каждый `.java` — отдельная работа, в том числе в подпапках. Пары без пагинации; сортировку и пороги задаёт фронт.

Новый ZIP возвращает `202`; повтор идентичных байтов возвращает `200`, тот же пакет и первоначальный `title`.
Дедупликация глобальная и постоянная по SHA-256 ZIP. Перепаковка может создать новый пакет. Уникальное
ограничение БД и транзакционная блокировка предотвращают дубли при параллельных запросах.
Без `title` используется имя архива; длина явного названия — до 200 символов.

Оценки двух методов не объединяются. Пока метод работает, оценка `null` с `RUN_NOT_FINISHED`;
при сбое — `RUN_FAILED`; при неразобранной работе — `NOT_PARSED`. Ноль — обычная оценка.
Если один метод упал, а второй завершился успешно, пакет получает `done`; подробности видны в `runs`.

Отзыв: `{"decision":"confirmed","comment":"..."}`. Решения: `confirmed`, `acceptable`, `false_positive`.
Комментарий необязателен, до 10000 символов. Один актуальный отзыв на пару, без автора и истории.
Ошибки: `{"code":"...","message":"...","details":{}}`.

## Проверки

При установленном JDK 25 и Maven 3.9+ из корня: `mvn -f api/pom.xml test`.
Лимиты ZIP: 10 МиБ сжатых данных, 5–50 работ, 1 МиБ на запись после распаковки, 50 МиБ суммарно,
200 записей с учётом служебных. Фактические размеры и CRC проверяются при чтении. Исходные тексты
UTF-8 или windows-1251 сохраняются в UTF-8, имена ZIP без UTF-8-флага читаются как CP866.

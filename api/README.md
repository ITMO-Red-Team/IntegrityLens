# api

Сервис между страницей и воркером. Принимает архив, кидает его в хранилище, ставит задачу в очередь, отдаёт статус и результаты.

## Контракт

`api/openapi.yaml` — единственный источник правды для `web/`.

## Зависимости и работа

Ничего ниоткуда не импортировать, общаться только с контейнерами. Подниматься тоже должно в контейнере.

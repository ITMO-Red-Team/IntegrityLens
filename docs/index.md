# IntegrityLens

IntegrityLens помогает преподавателю находить учебные работы, требующие
ручной проверки. Сервис сравнивает программный код, оценивает признаки
машинного происхождения и показывает основания для проверки.
Окончательное решение принимает преподаватель.

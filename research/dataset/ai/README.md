# ai

Работы, написанные ИИ: по две на задание. В датасете это `kind = ai`, `label = 1`.

Модель — `claude-opus-5-5`. Каждая работа получена отдельным запуском агента
с чистым контекстом: агент видел только запрос ниже и не читал файлы
репозитория. Код не запускался и не правился.

Запрос — фраза и условие задачи (раздел «Условие» из
`assignments/<id>/statement.md`):

- `1.java` — «Реши задачу на Java.», условие на русском;
- `2.java` — «Solve this competitive programming problem in Java 17. Give a
  complete single-file program with `public class Main` that reads stdin and
  writes stdout; the limits are large, so use fast I/O.», условие на английском
  (для a07 и a08 — без слов про fast I/O).

К запросу добавлялась техническая приписка: сохранить программу в файл, ничего
не читать и не запускать.

Генерация не воспроизводится: повторный запуск даст другой код. Файлы здесь —
единственная запись результата, `build.py` копирует их в задания как есть.
Правильность решений не проверялась.

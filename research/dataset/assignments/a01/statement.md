# a01. Parsa's Humongous Tree

Источник: Codeforces 1528A — https://codeforces.com/problemset/problem/1528/A

В ConPlag условий нет. Задача опознана по названиям классов в решениях, условие
пересказано своими словами; первоисточник — по ссылке.

## Условие

Дано дерево из `n` вершин. Для каждой вершины `v` задан отрезок `[l_v, r_v]`.
Нужно выбрать в каждой вершине целое число `a_v` из её отрезка так, чтобы сумма
`|a_u − a_v|` по всем рёбрам `(u, v)` была наибольшей, и вывести эту сумму.

Ввод. Первая строка — число тестов `t` (до 250). В каждом тесте: строка с `n`
(2 ≤ n ≤ 10^5); затем `n` строк, в `i`-й — `l_i r_i` (1 ≤ l_i ≤ r_i ≤ 10^9);
затем `n − 1` строк `u v` — рёбра дерева, вершины нумеруются с 1. Сумма `n` по
всем тестам не больше 2·10^5.

Вывод. Для каждого теста — одно число, наибольшая сумма.

## Особенности

- Решение каноничное: в оптимуме `a_v` равно `l_v` или `r_v`, дальше ДП по
  дереву с двумя состояниями на вершину. Честные решения похожи сами по себе.
- Работы сданы как есть, с личными шаблонами быстрого ввода. Один и тот же
  шаблон встречается у разных авторов и даёт высокое сходство без списывания.

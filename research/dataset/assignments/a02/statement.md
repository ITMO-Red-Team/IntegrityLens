# a02. Menorah

Источник: Codeforces 1615C — https://codeforces.com/problemset/problem/1615/C

Условие пересказано своими словами; первоисточник — по ссылке.

## Условие

Есть `n` свечей в ряд, каждая горит или не горит. Начальное состояние задано
строкой `a` из символов `0` и `1` (`1` — горит), нужное — строкой `b`.

За одну операцию выбирается горящая свеча: она остаётся гореть, а все остальные
свечи меняют состояние на противоположное.

Найти наименьшее число операций, которое превращает `a` в `b`, или вывести
`-1`, если это невозможно.

Ввод. Первая строка — число тестов `t` (до 10^4). В каждом тесте три строки:
`n` (1 ≤ n ≤ 10^5), строка `a` длины `n`, строка `b` длины `n`. Сумма `n` по
всем тестам не больше 10^5.

Вывод. Для каждого теста — одно число.

## Особенности

- Решение короткое: подсчёт совпадающих и различающихся позиций и разбор двух
  случаев по чётности числа операций.

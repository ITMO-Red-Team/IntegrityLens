# a03. Air Conditioners

Источник: Codeforces 1547E — https://codeforces.com/problemset/problem/1547/E

Условие пересказано своими словами; первоисточник — по ссылке.

## Условие

Полоса из `n` клеток, пронумерованных от 1 до `n`. В `k` различных клетках
`a_1, …, a_k` стоят кондиционеры, `j`-й настроен на температуру `t_j`.

Температура в клетке `i` равна минимуму по всем кондиционерам величины
`t_j + |a_j − i|`. Вывести температуру в каждой клетке.

Ввод. Первая строка — число тестов `q` (до 10^4). Перед каждым тестом идёт
пустая строка. В тесте три строки: `n k` (1 ≤ k ≤ n ≤ 3·10^5); `k` различных
чисел `a_j` (1 ≤ a_j ≤ n); `k` чисел `t_j` (1 ≤ t_j ≤ 10^9). Сумма `n` по всем
тестам не больше 3·10^5.

Вывод. Для каждого теста — `n` чисел через пробел: температуры в клетках
от 1 до `n`.

## Особенности

- Каноничное решение — два прохода, слева направо и справа налево.

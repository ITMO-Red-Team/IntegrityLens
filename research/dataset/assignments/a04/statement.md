# a04. Phoenix and Towers

Источник: Codeforces 1515C — https://codeforces.com/problemset/problem/1515/C

Условие пересказано своими словами; первоисточник — по ссылке.

## Условие

Есть `n` блоков, высота `i`-го — `h_i`, каждая высота не больше `x`. Нужно
сложить из всех блоков ровно `m` башен: каждый блок идёт в одну башню, в каждой
башне хотя бы один блок. Высота башни — сумма высот её блоков. Башни красивы,
если высоты любых двух отличаются не больше чем на `x`.

Вывести, можно ли построить красивые башни, и если да — распределение блоков.

Ввод. Первая строка — число тестов `t` (до 1000). В каждом тесте две строки:
`n m x` (1 ≤ m ≤ n ≤ 10^5, 1 ≤ x ≤ 10^4) и `n` чисел `h_i` (1 ≤ h_i ≤ x).
Сумма `n` по всем тестам не больше 10^5.

Вывод. Для каждого теста: `NO`, если построить нельзя; иначе `YES` и во второй
строке `n` чисел `y_i` (1 ≤ y_i ≤ m) — номер башни для `i`-го блока. Подходит
любой правильный ответ.

## Особенности

- Каноничное решение жадное: очередной блок кладётся в самую низкую башню,
  башни лежат в очереди с приоритетом.

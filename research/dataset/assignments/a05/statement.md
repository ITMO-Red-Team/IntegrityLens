# a05. Interesting Story

Источник: Codeforces 1551C — https://codeforces.com/problemset/problem/1551/C

Условие пересказано своими словами; первоисточник — по ссылке.

## Условие

Дано `n` слов, каждое состоит только из букв `a`, `b`, `c`, `d`, `e`. Рассказ —
это набор слов (слова могут повторяться). Рассказ интересный, если в нём есть
буква, которая встречается строго чаще, чем все остальные буквы вместе взятые.

Найти наибольшее число слов, которые можно выбрать из данных, чтобы получился
интересный рассказ. Если такого набора нет, вывести 0.

Ввод. Первая строка — число тестов `t` (до 5000). В каждом тесте: строка с `n`
(1 ≤ n ≤ 2·10^5), затем `n` строк — непустые слова. Сумма `n` по всем тестам не
больше 2·10^5, суммарная длина слов не больше 4·10^5.

Вывод. Для каждого теста — одно число.

## Особенности

- Каноничное решение: для каждой из пяти букв посчитать у каждого слова
  «число этой буквы минус число остальных», отсортировать и набирать жадно.

# a06. Minimum Grid Path

Источник: Codeforces 1499C — https://codeforces.com/problemset/problem/1499/C

Условие пересказано своими словами; первоисточник — по ссылке.

## Условие

Нужно дойти из точки `(0, 0)` в точку `(n, n)`. Путь состоит из отрезков,
каждый идёт либо вправо, либо вверх и имеет положительную целую длину.
Направления соседних отрезков чередуются, первый отрезок может идти в любую из
двух сторон. Всего в пути не больше `n` отрезков (то есть не больше `n − 1`
поворота).

Заданы стоимости `c_1, …, c_n`. Стоимость пути из `k` отрезков равна сумме
`c_i · длина_i` по `i` от 1 до `k`. Найти наименьшую стоимость пути.

Ввод. Первая строка — число тестов `t` (до 1000). В каждом тесте две строки:
`n` (2 ≤ n ≤ 10^5) и `n` чисел `c_i` (1 ≤ c_i ≤ 10^9). Сумма `n` по всем
тестам не больше 10^5.

Вывод. Для каждого теста — одно число, наименьшая стоимость.

## Особенности

- Каноничное решение: перебор числа отрезков с поддержкой сумм и минимумов
  отдельно по чётным и нечётным позициям.

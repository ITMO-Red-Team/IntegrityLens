# a08. Monsters And Spells

Источник: Codeforces 1626C — https://codeforces.com/problemset/problem/1626/C

Условие пересказано своими словами; первоисточник — по ссылке.

## Условие

Уровень длится много секунд, появляется `n` монстров. `i`-й монстр появляется
в секунду `k_i` и имеет здоровье `h_i`, причём `h_i ≤ k_i`.

В каждую секунду можно применить заклинание или не применять. Урон заклинания:
если в предыдущую секунду заклинание не применялось — 1; если применялось с
уроном `x` — на выбор `x + 1` или 1. Заклинание с уроном `x` стоит `x` маны.
Чтобы убить `i`-го монстра, в секунду `k_i` нужно применить заклинание с
уроном не меньше `h_i`.

Найти наименьшее количество маны, чтобы убить всех монстров.

Ввод. Первая строка — число тестов `t` (до 10^4). В каждом тесте три строки:
`n` (1 ≤ n ≤ 100); `n` чисел `k_1 < k_2 < … < k_n` (1 ≤ k_i ≤ 10^9); `n` чисел
`h_i` (1 ≤ h_i ≤ k_i). Сумма `n` по всем тестам не больше 10^4.

Вывод. Для каждого теста — одно число.

## Особенности

- Каноничное решение: каждому монстру соответствует отрезок секунд
  `[k_i − h_i + 1, k_i]`, пересекающиеся отрезки объединяются, ответ — сумма
  `L·(L+1)/2` по длинам объединённых отрезков.

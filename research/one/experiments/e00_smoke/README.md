# e00 — инструменты считают то же, что в `tools/`

```bash
uv run python experiments/e00_smoke/run.py
```

Результат: [`results/e00_smoke/checks.json`](../../results/e00_smoke/checks.json).

## Зачем

В `tools/` оба инструмента запускаются в Docker. Здесь Docker не используется:
JPlag запускается из jar на локальной JDK, а шаг 1 structsim (`semgrep-core`)
берётся из pip-пакета semgrep той же версии. Правило 3 из
[tools/README.md](../../../../tools/README.md): «запустился» и «сработал» —
разные вещи. Поэтому до основных экспериментов замену проверяем на входе, для
которого ответ известен заранее.

Третий инструмент, Dolos (для [e04](../e04_dolos/README.md)), в `tools/` нет.
Он ставится `npm ci` по `package-lock.json` в `research/one/node_modules/`, и
для него проверяется то же на alice/bob/carol: прибитая версия, все файлы
разобраны, ожидаемые оценки.

`tools/jplag/usage.md`: тех в репозитории нет.

## Интерпретация

Локальная замена шага 1 даёт **те же метки**, что контейнер, на всех
сохранённых выгрузках, включая все девять языков. Значит, оценки structsim
в следующих экспериментах — оценки самого structsim, а не артефакт запуска без
Docker. JPlag на локальной JDK 25 разбирает Java (`javac` на месте) и даёт
ожидаемые 1.0 и 0.0.

Уже здесь видна разница шкал. Пара разных программ получает у JPlag ровно
0.0: общих кусков длиной от 9 меток нет. У structsim та же пара получает
0.376, потому что у любых двух Java-программ есть общий каркас (`class`,
`main`, `Scanner`, печать). Нулей structsim почти не выдаёт. Dolos между
ними: 0.222. Минимальная длина общего куска у него больше, чем у JPlag (23
метки против 9), но метки мельче — типы узлов дерева вместе со скобками, — и
у alice и carol находится 10 общих отпечатков из 34 и 56; самый длинный общий
фрагмент — 7 k-грамм подряд.

## Вывод

Оба инструмента работают локально без Docker и считают то же, что в
`tools/`. Dolos работает локально в прибитой версии. Сырые числа двух инструментов нельзя сравнивать напрямую: у
structsim выше нижняя граница. Поэтому дальше сравнивается не уровень оценок,
а то, **насколько хорошо они отделяют плагиат** (ROC-AUC, AP).

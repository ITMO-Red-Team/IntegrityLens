# Фикстуры

Вход, ответ для которого известен заранее. На нём `doctor` проверяет не
«инструмент запустился», а «инструмент выдал ожидаемые числа».

| | |
|---|---|
| `jplag/alice` | максимальная сумма подотрезка (Кадане) |
| `jplag/bob` | тот же код `alice`, переименованы все переменные → JPlag обязан дать `1.0` |
| `jplag/carol` | другая задача (НОД), другой ввод → при `-t 9` общих кусков нет, `0.0` |

Для structsim фикстуры свои не нужны: `doctor` берёт выгрузки и исходники из
[`tools/structsim/tests/data/langs`](../../../tools/structsim/tests/data/README.md),
на которых держатся тесты самого инструмента.

# aicode

Локальная эвристическая проверка исходного кода на AI-похожие фрагменты.
Модель возвращает интервалы символов и уверенность, CLI переводит их в строки
и показывает долю отмеченных символов. Это **не** доказательство авторства и
не оценка вероятности происхождения всего файла.

## Как запустить

Обычно используется Docker-образ с уже упакованной квантованной моделью:
CPU, без GPU, укладывается в 5 GB RAM.

```bash
docker run --rm --memory=5g -v "<каталог с кодом>:/work:ro" \
    integritylens/aicode:0.1.1 /work
```

Аргумент — файл или каталог с `.java`.
Полезные флаги: `--json` — машинно-читаемый отчёт; `--threshold X` — минимальный
confidence спана (по умолчанию 0.8)

Если образ ещё не собран — один раз скачайте готовые артефакты модели
(~1.6 GB, нужен любой Python 3 без зависимостей) и соберите образ (модель при
сборке из сети не качается):

```bash
(cd tools/aicode && python fetch_model.py)
docker compose -f tools/docker-compose.yml build aicode
```

Локальный экспорт, int4 и запуск без Docker — в [docs/usage.md](docs/usage.md).

## Что на выходе

По каждому файлу — `FLAGGED`, процент символов, попавших в найденные
фрагменты, и список `lines N-M: confidence C`. `FLAGGED` — не общая
уверенность для файла. Проверенный прогон на валидационном датасете
`research/dataset/ai` (16 AI-сгенерированных работ, порог по умолчанию 0.8,
≈8 минут) — все 16 файлов дают одинаковый результат:

```text
FILE                                               FLAGGED   SPANS
/work/ai/a01/1.java                                  0.00%       0
/work/ai/a01/2.java                                  0.00%       0
/work/ai/a02/1.java                                  0.00%       0
…                                                     …          …
```

Честный итог: в текущей конфигурации качество детекции **не отделяет AI-код
от человеческого**. На пороге по умолчанию детекций нет вовсе; на низком
пороге (0.05) спаны появляются, но уверенность честной работы выше, чем у
AI-работ (реальный прогон: 2 AI-работы из датасета и честная работа
`assignments/a01/works/028ea375…`):

| файл | метка | FLAGGED | спанов | max confidence |
|---|---|---|---|---|
| `ai/a01/1.java` | ИИ | 80.6% | 4 | 0.458 |
| `ai/a02/2.java` | ИИ | 65.7% | 1 | 0.360 |
| честная работа a01 | человек | 45.5% | 1 | 0.544 |

Сам пайплайн при этом работает: файлы разбираются, спаны маппятся в строки.
Причины, замеры и возможное направление — в
[docs/how-it-works.md](docs/how-it-works.md).

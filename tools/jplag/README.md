# jplag

**JPlag 6.3.0** — поиск плагиата в исходном коде по алгоритму Greedy String
Tiling. Развивается с 1996 года, стандартный инструмент сравнения в этой
области.

В этом проекте используется как **baseline** — та мера, с которой
сопоставляются другие.

Сравнивает программы только на одном языке — кросс-языковые пары не умеет в
принципе. Это граница инструмента, а не его проигрыш.

## Сборка

```bash
docker compose -f tools/docker-compose.yml build jplag
```

Что образ собрался — ещё не значит, что инструмент работает: на образе без JDK
JPlag запускается и молча не разбирает ни одного файла, сообщая только
«found 0 valid submissions». Поэтому проверять его надо входом, ответ для
которого известен заранее — см.
[usage.md](usage.md#почему-именно-jdk).

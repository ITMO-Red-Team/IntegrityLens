# native: шаг 3 и тайлы на Rust

Те же числа, что у `compare.py` и `tiles.py`, бит в бит. 50 решений ConPlag, все пары, одно ядро:
эталон 58 с, native 0.13 с. Замеры — [`worker/bench/README.md`](../../../worker/bench/README.md).

## Сборка и запуск

```bash
cargo build --release --manifest-path tools/structsim/native/Cargo.toml
```

```python
from structsim import native

pairs = native.score_all(programs)   # порядок как у combinations(programs, 2)
```

Бинарник: `STRUCTSIM_NATIVE`, затем `structsim-native` в `PATH`, затем `native/target/release`.
`STRUCTSIM_NATIVE=off` — не искать.

## Совпадение с эталоном

[`tests/test_native.py`](../tests/test_native.py) сравнивает через `==` на случайных и настоящих
программах. На 1225 парах ConPlag 0 расхождений. Повторено:

- выбор куска в `SequenceMatcher`: самый длинный, среди равных левый в `a`, затем в `b`;
- несимметричность `ratio(a, b)` и `ratio(b, a)`;
- `sum()` CPython ≥ 3.12 с компенсацией Ноймайера;
- порядок тайлов: от длинных к коротким, внутри прохода по `(i, j)`.

## Откуда скорость

| Что | Эталон | native |
|---|---|---|
| поиск самого длинного куска | по вхождениям одной метки | по кускам из 6 меток, на диапазонах от 32 меток |
| индекс вхождений | на каждое сравнение | раз на последовательность |
| мера по функциям | `B²`, дважды | пока верхняя граница выше найденного |
| мера по фрагментам | множества на каждую пару | отсортированные списки, слияние |
| тайлы | все пары позиций за проход, `T³` | совпавшие начала, куча по длине |

Совпадение хешей кусков ответ не портит: лучший кусок сверяется по меткам, при расхождении поиск
повторяется без индекса. Оценка пары `T^1.3…1.6` вместо `T²`, тайлы `T^1.9` вместо `T^2.7`
([`pair_cost.csv`](../../../worker/bench/results/pair_cost.csv)).

## Формат

stdin и stdout, текст, разделитель — пробел или перевод строки.

```
structsim-native/3 <программ> <меток в алфавите> <min_tile> <потоков>
<T> <метка>×T <строка>×T <B> (<длина блока> <метка>×длина)×B
```

Для сравнения с источниками `structsim-native/4` добавляет после числа потоков флаг
`0` или `1` для каждой программы. В выход входят пары с хотя бы одной целевой
программой (флаг `1`). Python передаёт флаги через аргумент `targets`.

Метка — номер от 0, строка — номер строки или 0. `min_tile = 0` — без тайлов, `потоков = 0` — все
доступные. Алфавит до 4096 меток. Выход, строка на пару в порядке `combinations`:

```
<a> <b> <order> <shingle> <blocks> <combined> <containment> <final> <K> (<start_a> <start_b> <length> <a_from> <a_to> <b_from> <b_to>)×K
```

Числа — кратчайшая запись, которая разбирается в то же значение. `STRUCTSIM_NATIVE_TIMINGS=1` —
время этапов в stderr.

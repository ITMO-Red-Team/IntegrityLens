# Данные для тестов

Выгрузки `semgrep-core -lang <язык> -json -full_token_info -dump_ast`,
снятые на Semgrep 1.180.0, плюс исходники, из которых они получены.

Лежат здесь, чтобы тесты шага 2 не требовали Docker: обход дерева — чистая
функция от этого JSON, и держать её проверку быстрой важнее, чем генерировать
вход каждый раз.

| Файл | Зачем |
|---|---|
| `relax.cpp`, `relax.py` + их `.json` | пример из разбора метода. На нём проверяется и точная ожидаемая последовательность меток, и то, что C++ с Python сходятся |
| `rich.py` + `rich.py.json` | покрывает остальную таблицу: циклы, `elif`/`else`, литералы, кортеж, список, `continue`/`break`/`return`, рекурсивный вызов |

Пересоздать:

```bash
docker compose -f tools/docker-compose.yml build semgrep
docker run --rm --mount "type=bind,source=$PWD/tools/structsim/tests/data,target=/work,readonly" \
  integritylens/semgrep:1.180.0 \
  semgrep-core -lang cpp -json -full_token_info -dump_ast /work/relax.cpp
```

## langs/

Один и тот же алгоритм (сумма положительных элементов) на девяти языках и
выгрузки их деревьев. На них держится `test_convergence.py` — единственная
проверка, которая ловит ошибки таблицы шага 2: они не падают, а молча
снижают оценку.

Добавляя язык, положите сюда файл и допишите его в `CONVERGENT`.

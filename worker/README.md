# Воркеры

Два воркера берут задания из PostgreSQL и скачивают исходники из MinIO. Structsim обрабатывает снимок ревизии по контракту `integritylens.core/2`. AI обрабатывает одну сдачу по контракту `integritylens.ai/1`. Форматы описаны в [контрактах](../docs/contracts.md#контракты-воркеров).

Воркеры обновляют heartbeat во время обработки. После истечения аренды задание доступно для повторной попытки. Публикация проверяет владельца, номер попытки и актуальность ревизии Structsim. Результаты хранятся в PostgreSQL, рабочие файлы удаляются после прогона.

При остановке воркера или потере аренды процесс анализатора завершается вместе с дочерними процессами. `CORE_TIMEOUT_SECONDS` задаёт предел прогона. Ошибка отдельного файла или пары сохраняется в результате, временный сбой прогона допускает повтор.

## Моки

Сценарий задаётся через `STRUCTSIM_MOCK_SCENARIO` или `AI_MOCK_SCENARIO` в Compose после включения моков. `MOCK_DELAY_SECONDS` добавляет задержку.

| Сценарий | Результат |
| --- | --- |
| `success` | Все работы обработаны |
| `partial` | Ошибка одной работы |
| `fail_once` | Первая попытка падает, повтор успешен |
| `tool_error` | Все попытки падают |
| `invalid_input` | Ошибка без повторов |
